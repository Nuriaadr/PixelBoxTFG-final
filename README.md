# PixelBox – Plataforma Gamer

## Descripción
PixelBox es una aplicación web inspirada en Letterboxd, orientada a la comunidad gamer. Permite a los usuarios descubrir, valorar y compartir vivencias, ofreciendo una experiencia social centrada en el mundo de los videojuegos.

El proyecto está desarrollado con:

- Frontend: HTML, CSS y JavaScript
- Backend: Slim Framework

Se ha diseñado con un enfoque responsive para garantizar una experiencia óptima en dispositivos móviles, tablets y escritorio.

---

## Características principales

- Diseño responsive adaptable a distintos dispositivos
- Interactividad dinámica mediante JavaScript
- Plataforma social para compartir opiniones sobre videojuegos
- Arquitectura ligera basada en Slim Framework
- Navegación fluida centrada en la experiencia de usuario

---

## Instrucciones de ejecución

### Frontend
Para ejecutar el proyecto en local, sigue estos pasos:

1. Clona este repositorio en tu máquina local:
```bash
git clone https://github.com/Nuriaadr/PixelBoxTFG-master.git
cd PixelBoxTFG-master
```

2. Abre el archivo index.html en tu navegador:
- Haz doble clic en el archivo
- Usa una extensión como Live Server en VS Code
- Accede mediante GitHub Pages

### Backend (opcional)
Para ejecutar el backend con Slim Framework:

1. Asegúrate de tener instalado:
- PHP
- Composer
2. Instala las dependencias:
  ```bash
  composer install
  ```
3. Inicia el servidor:
 ```bash
php -S localhost:8000
```
4. Accede desde el navegador: 
```bash
http://localhost:8000
```
